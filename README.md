# The Iconic Hotel - Web Platform

ASP.NET MVC web platform for **The Iconic** hotel brand experience: public site pages plus operational/admin tooling.

## Overview
Hotel website solution with reservation-oriented flows, room/content presentation, and management screens.

## Key Features
- Public hotel website pages
- Rooms / gallery / content modules
- Booking and reservation workflows
- Admin management support
- SQL Server data access

## Tech Stack
- **Backend:** ASP.NET MVC (C#)
- **Frontend:** Razor, JavaScript, jQuery, Bootstrap
- **Database:** Microsoft SQL Server
- **Solution:** `MountFeastMVC.sln`
- **App folder:** `MountFeastMVC/`

## Getting Started
1. Open the solution in Visual Studio
2. Update connection strings for your environment
3. Restore NuGet packages
4. Build and run under IIS Express
